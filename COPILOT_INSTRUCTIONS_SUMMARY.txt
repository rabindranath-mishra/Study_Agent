   • 10 canonical directories (System, Inbox, Sources, etc.)
   • Immutable organizational rules
   • File naming conventions
   • Directory-to-note-type mappings

4️⃣  METADATA STANDARDS
   • 11 note types (source, concept, practice, etc.)

   • Content structure templates
   • Metadata validation rules

5️⃣  PYTHON CODE STANDARDS
   • Style: PEP 8 (modified for 100-char lines)
   • Docstrings: Google style (required)
   • Type hints: Required for all public functions
   • Error handling: Specific exceptions, no bare except
   • Logging: Python logging module (not print)
   • Testing: pytest with coverage requirements

6️⃣  GOVERNANCE POLICIES (SACRED)
   
   🛡️ Vault Containment
      • All artifacts MUST stay in vault directories
      • No external storage for learner state
      • Exceptions: binaries, cache, temp files
   
   ✋ File Write Governance
      • Backend proposes → Student approves → Write
      • Safe automatic writes: logs, state, cache
      • Approval-gated: notes, quizzes, plans
   
   📚 Source & Grounding
      • Never fabricate when uncertain
      • Preserve provenance through transformations
      • 7-tier source trustworthiness hierarchy
   
   🎓 Educational Behavior
      • Progressive disclosure (hints before solutions)
      • Level adaptation (adjust to student understanding)
      • Independence building (not dependency)

7️⃣  COMMON WORKFLOWS
   Three fully documented workflows:
   
   A. Student Asks Question
      → Classify → Route → Retrieve → Explain → Update State
   
   B. Generate Practice Quiz
      → Analyze Mastery → Prioritize Weak Areas → Generate → Validate
   
   C. Create Revision Plan
      → Load Mastery → Calculate Schedule → Apply Spaced Repetition

8️⃣  TESTING & VALIDATION

   • Fact checker validation with confidence scoring
   • Compliance validation (Constitution enforcement)
   • Test examples with pytest patterns

9️⃣  STATE MANAGEMENT
