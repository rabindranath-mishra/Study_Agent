   ✅ Teaching agent knows pedagogical strategies

2. SEPARATION OF CONCERNS
   ✅ Clear boundaries between responsibilities
   ✅ Easier to test individual components
   ✅ Easier to debug specific functionality

   ✅ Agents can coordinate through orchestrator

5. BETTER PROMPTING
   ✅ Each agent has optimized system prompt
   ✅ Focused context reduces hallucination
   ✅ Clearer role definitions
   ✅ Better tool selection

📋 AGENTS TO BUILD (RECOMMENDED):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TIER 1 - CORE STUDY AGENTS (Must Build):

1. teaching_agent.py
   Purpose: Explain concepts pedagogically
   Responsibilities:
   • Retrieve concept from vault or web
   • Adapt explanation to student level
   • Generate examples and analogies
   • Create concept notes with proper structure
   • Apply teaching strategies (scaffolding, etc.)
   Tools: vault_search, web_search, create_note, templates
   
2. practice_agent.py
   Purpose: Generate assessments
   Responsibilities:
   • Create quizzes aligned to learning objectives
   • Generate flashcards for memorization
   • Design practice problems
   • Adjust difficulty based on mastery
   • Create practice notes
   Tools: vault_search, mastery_store, create_note, templates

3. diagnostic_agent.py
   Purpose: Analyze learning and update progress
   Responsibilities:
   • Evaluate student answers
   • Classify errors (conceptual vs careless)
   • Identify knowledge gaps
   • Update mastery levels
   • Recommend remediation
   Tools: mastery_store, vault_search, activity_log
   
4. revision_planner_agent.py
   Purpose: Create study plans
   Responsibilities:
   • Analyze mastery levels
   • Calculate spaced repetition schedule
   • Prioritize by exam proximity and weakness
   • Generate daily study plans
   • Create revision plan notes
   Tools: mastery_store, exam_calendar, revision_queue, create_note

TIER 2 - SUPPORTING AGENTS (Should Build):

5. knowledge_agent.py
   Purpose: Retrieve and validate information
   Responsibilities:
   • Search vault with confidence scoring
   • Escalate to web if needed
   • Fact-check claims
   • Assess source quality
   • Maintain provenance
   Tools: vault_search, web_search, fact_checker, contradiction_check

6. memory_agent.py
   Purpose: Manage learner state
   Responsibilities:
   • Track learning history
   • Maintain mastery records
   • Update revision queue
   • Preserve session context
   • Generate progress analytics
   Tools: All state stores (profile, mastery, queue, calendar, log)

TIER 3 - OPTIONAL AGENTS (Build Later):

7. curriculum_agent.py
   Purpose: Structure learning paths
   Responsibilities:
   • Define subject structure
   • Identify prerequisites
   • Sequence topics
   • Align to exam syllabus
   Tools: vault_search, create_note

8. output_agent.py
   Purpose: Format study artifacts
   Responsibilities:
   • Apply note templates
   • Ensure consistent formatting
   • Add proper frontmatter
   • Validate compliance
   Tools: templates, compliance_agent, create_note

9. profile_agent.py
   Purpose: Manage learner profiles
   Responsibilities:
   • Onboard new students
   • Track preferences
   • Manage exam targets
   • Personalize experience
   Tools: learner_profile_store

🔄 HOW ORCHESTRATION WORKS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Student: "Explain photosynthesis"
    ↓
Copilot CLI: Classifies intent → "teaching"
    ↓
Copilot CLI: Calls teaching_agent.py
    ↓
Teaching Agent:
    1. Calls vault_search_agent.py ("photosynthesis")
    2. If confidence low, calls web_search_agent.py
    3. Adapts explanation to student level
    4. Calls create_note.py with concept template
    5. Returns formatted response
    ↓
Copilot CLI: Presents to student in chat
    ↓
Plugin: Shows approval dialog for note creation

Student: "Create a quiz on photosynthesis"
    ↓
Copilot CLI: Classifies intent → "practice"
    ↓
Copilot CLI: Calls practice_agent.py
    ↓
Practice Agent:
    1. Calls mastery_store.py (get current level)
    2. Calls vault_search_agent.py (get content)
    3. Generates questions at appropriate difficulty
    4. Calls create_note.py with practice template
    5. Returns quiz
    ↓
Copilot CLI: Presents quiz in chat
    ↓
Plugin: Shows approval dialog

Student: Submits answers
    ↓
Copilot CLI: Calls diagnostic_agent.py
    ↓
Diagnostic Agent:
    1. Evaluates answers
    2. Classifies errors
    3. Calls mastery_store.py (update levels)
    4. Calls memory_agent.py (log activity)
    5. Returns feedback + updated mastery
    ↓
Copilot CLI: Shows feedback to student
